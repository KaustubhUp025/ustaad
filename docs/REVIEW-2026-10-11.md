## 1. Do first

- [ ] **Registration closes today (Oct 11).** T01 is still `todo`. The site also says working professionals
      only, 21+, and that teams with students are disqualified even after shortlisting. Confirm both members qualify.
- [ ] **`infra/smoke_live.py` does not match Gemini 3.8 Live** (T05 will probably fail on the default model):
  - Text turns use `send_client_content` without `initial_history_in_client_content=True`; the 3.8 Live guide
    sends text with `send_realtime_input(text=...)`.
  - Bengali is listed as `bn-BD` on Agent Platform; the script uses `bn-IN`.
  - Google's docs disagree on `speech_config.language_code`: the Gemini API Live guide says native-audio models
    choose the language themselves and don't accept it; the Agent Platform page shows it being set. Test both,
    and force the language in the system instruction ("RESPOND IN <language>. YOU MUST RESPOND UNMISTAKABLY IN
    <language>."), which is what the docs recommend.
  - The receive loops have no timeout, so the script hangs if `turn_complete` never arrives.
  - It does not exercise a tool call, though the base workflow (T05) and spec §11 ask for one.
- [ ] **`LIVE_LOCATION` defaults to `us-central1`.** `gemini-3.8-live` is listed on `global` and `asia-south1`.
      A US region works against the 2.5 s reply target for workers in India. Test `global` and `asia-south1`
      in T05 and keep the faster one. Regional endpoints cost about 10% more than `global`.

## 2. Plan vs current Google Cloud products

### Change
- [ ] **Tool results for 3.8 Live.** The guide asks for tool responses carrying `status`, `retryable` and
      `message`, and a system-instruction rule capping consecutive tool calls at two. Otherwise the model may
      repeat a call when a tool returns nothing (e.g. `search_fault_cards` with no match). This touches the tool
      contracts, so decide before the Monday 12:00 freeze.
- [ ] **Transcription decision is due a revisit.** `gemini-3.5-transcribe` is now listed as stable and in all
      regions; SPEC still says "preview, Interactions API". `DECISIONS.md` says revisit on GA. Keep Flash as the
      default; compare both on 10 Hinglish notes on Day 2 with the existing `TRANSCRIBE_MODEL` flag.
- [ ] **Embeddings.** `gemini-embedding-001` at 768 dims is not auto-normalised: the Firestore index and the
      dedupe step must use cosine distance, or normalise the vectors. `gemini-embedding-2` is now stable and
      auto-normalises; staying on 001 this week is fine, but record the cosine rule.
- [ ] **Names judges will read.** Vertex AI → Agent Platform; Agent Engine → Agent Runtime; Vertex AI Search →
      Agent Search (the console still says Vertex AI Search). Use the new names in the README and deck. APIs and
      code are unchanged.
- [ ] **Deadline wording.** The official deadline is Oct 18. Our Oct 17, 21:00 IST is a self-imposed buffer; say
      so in SPEC so the 18th is not treated as slack.

## 4. Repo: will bite on day one

- [ ] **`make deploy-hosting` can ship localhost URLs.** SETUP says copy `web/.env.example` to `web/.env.local`;
      Vite loads `.env.local` for production builds too. Nothing defines where the demo `wss://` URL comes from.
      Fix: a committed `web/.env.production`, or have the target pass both values and fail on `localhost`.
- [ ] **Node version.** SETUP and CI say 22, SPEC §9 says 20. Pick one and add `web/.nvmrc` or `engines`.
      (Kaustubh's laptop has Node 18 and no `pnpm` or `firebase`; needed before T04.)
- [ ] **Fixtures are outside the Docker build.** `deploy.sh` ships only `backend/`, but T09/T10 have the server
      read `seed/fixtures/`. Works locally, fails on Cloud Run. Move server-read fixtures under `backend/` or
      build from the repo root.
- [ ] **Background work on Cloud Run.** "Return 200, process in the background" stalls without
      `--no-cpu-throttling`. No `--memory` / `--cpu` set either, and ffmpeg is in the image.
- [ ] **Signed uploads.** `infra/setup.sh` does not enable `iamcredentials.googleapis.com` and sets no CORS on
      the media bucket for browser `PUT`. (`cloudresourcemanager.googleapis.com` is also not enabled; unverified
      whether it is needed.)
- [ ] **Teammate deploys may come out private** (unverified). `--allow-unauthenticated` needs
      `run.services.setIamPolicy`, which `roles/editor` lacks. Grant `roles/run.admin` or let B do first deploys.
- [ ] **Hosting always rewrites `/api/**` to the demo service** (`firebase.json`), so preview channels hit demo
      data. Document that dev web sets `VITE_API_URL` to the dev Cloud Run URL, or add a second hosting target.
