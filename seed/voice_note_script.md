# Voice-note recording script (task T08)

Goal: a real WhatsApp group "AC Mistri Noida" whose export becomes the import demo (SPEC §4, §10).
Members: the team plus friends who agree in writing that their recordings can be used in the demo.

## Before recording
- For each fault below, look up the **real** error-code meaning and fix in that brand's service manual
  (the same PDFs loaded into Agent Search). Fill the blanks. Never invent a code's meaning.
- Speak naturally in Hinglish (and a few in Telugu), 20–60 seconds each, phone held normally, a little
  background noise is fine. Use first names only.

## Pattern for each fault (3–4 messages)
1. Question (text or voice): "Bhai, <brand> <tonnage> inverter, indoor pe <code> blink kar raha hai, outdoor chal nahi raha. Kya check karun?"
2. Senior's answer (voice, 30–60 s): what the code means per the manual, what to check first, the safety step, the part that usually fails.
3. Follow-up (voice or text): "Check kiya, <part> kharab tha, badal diya, ho gaya." + optionally a photo of the board or nameplate.
4. Optional disagreement or alternative fix from someone else (gives the dedupe/merge step something to do).
