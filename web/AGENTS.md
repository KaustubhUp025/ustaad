# web/ — local rules (the root AGENTS.md also applies)

- Routes: `src/routes/w/*` worker app (mobile first) · `src/routes/d/*` dashboard (desktop) · audio in `src/audio/`.
- Read `docs/DESIGN.md` before UI work and follow `docs/playbooks/ui-pass.md`. Tokens only from `src/styles/tokens.css`
  (via Tailwind theme mapping); no raw hex, no new fonts.
- Strings only in `src/i18n/{en,hi,te,ta,bn}.json`. Sentence case. Button text says what happens.
- Data: REST through TanStack Query hooks in `src/api/`; types in `src/api/types.ts`, generated by `make types` (never edit).
- Live voice: `wss://` straight to the Cloud Run URL (`VITE_API_WS_URL`), never through Firebase Hosting.
- Env: `web/.env.local` (copy `web/.env.example`). With `VITE_MOCK_LIVE=1` the job screen replays
  `/mock/live_session.jsonl` (run `make mock` first), so UI work needs no backend.
- Dev talks to the dev Cloud Run URL via `VITE_API_URL`; the deployed build uses same-origin `/api` (Hosting rewrite).
- No direct Firestore access from the browser. Live import progress and quotes: poll REST every 2 s while visible.
- Check at 360 px width; 48 px touch targets; visible focus; `prefers-reduced-motion` respected.
